# Lychee Dev

Lychee Dev is a lightweight graphical World of Warcraft Retail 12.1+ data inspection tool.

GitHub: https://github.com/Follen/Lychee-Dev

Type `/dev` to open the window, paste Lua generated by an Agent, and click **Run**. Input may include a leading `/run` or `/script`. Returned values can be inspected as an expandable tree or copied as text. The Events view searches all 1,782 documented Retail 12.1 events, shows their Payload signatures, and captures only the events selected before **Start**. Searching for `ALL` or `全部` exposes an explicit all-events mode backed by `RegisterAllEvents`; it is never enabled by default.

The tree inspector loads large tables in pages of 200 entries and creates nested nodes only when they are expanded. UI objects expose their basic properties, child frames, regions, and Lua fields without recursively walking the entire hierarchy up front. The event monitor remains inactive until **Start** is clicked, unregisters everything on **Stop**, and keeps the newest 500 records in memory with a virtualized event list.

Click **Select result**, then press `Ctrl+C` to copy the result. World of Warcraft addons cannot write directly to the operating system clipboard.

Recent runs are stored in `LycheeDevDB` under a 16 MB total storage budget rather than a fixed entry count. Existing `DumperDB` history is migrated automatically. Each stored input and result also has an individual size limit so SavedVariables cannot grow without bound.
