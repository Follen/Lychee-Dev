# Current and historical Source / Data evidence

The `*-public.mjs` old Data SQL/DB2 differential tools and stream SDK differential
are historical migration-oracle tools, not current Agent acceptance. They require
`--historical-oracle-only`; selecting that mode does not qualify a current artifact
or silently restore retired commands. Historical fixture/report bytes remain
unchanged. The current paths are the owned Agent paired collectors, installed
Skill Agent workflow, supervised pipe/deadline tools, and typed Engine/domain
native declarations. All reconstructed-candidate execution remains NOT_RUN.

# Source / Data migration fixtures

`addon-closure` is an independently readable Lua 5.1 fixture for ordered TOC/XML
expansion, repeated load evidence, CJK paths, cycle diagnostics and root escape.
Source library tests archive its exact bytes and preserve load-edge provenance.
Real luac/LuaLS process tests live in the Source crate and require explicit fixed
tool stages; they are ignored during ordinary fixture tests.

Data suites cover authenticated local CASC/Encoding ranges, DBD/WDC, physical
XFTH, selected typed SQL, cache/keys and shared budget boundaries. Real client
fixtures are explicitly ignored in ordinary runs and require an isolated home.
`db2-public-differential.mjs` compares ten fixed local Retail public CLI cases;
`sql-simple-public.mjs` compares the retained Unicode simple-casing cases.
`generate-unicode-simple.mjs` reproduces official pinned Unicode17 static data;
the Go adapter's `unicode-simple` mode is test-only, never a product backend.
Reports preserve first failures and distinguish actual resource observations.
Full SQL/domain/partial/network/asset export and Source command/matrix parity
remain incomplete; the progress ledger gives exact acceptance boundaries.

`environment-cases.json` and `environment-go.json` preserve16 exact frozen-Go
literal/declaration cases and one separately labeled standard Lua5.1 `goto`
identifier improvement. The test-only oracle's `environment` mode generates
these comparisons; it is not called by Rust production. `environment-differential.mjs`
compares the complete fixed Blizzard catalog captured by the explicit ignored
`environment_real` test. `semantic_validate_real` checks the Source public SDK
dispatcher with authenticated luac/LuaLS and original XML diagnostic lines;
packaged CLI acceptance is a separate gate. First failed real assertions stay
in the progress ledger's original logs.

`joins-cases.json`/`joins-go.json` preserve14 ordered inner/left/cross fixture
results and errors from frozen Go. `joins-public.mjs` compares8 sequential
actual local Map/ChrClasses public CLI cases, retaining all typed rows, schemas,
fixed content/key-source identities and verified captures. It supports
`LYCHEEDEV_RUST_BIN` for a frozen executable and `LYCHEEDEV_JOIN_OFFLINE_ONLY=1`
after exact DBD preparation. Failed first public LEFT JOIN budget evidence
remains in the ledger; these selected cases are not full SQL/performance gates.

`matrix-cases.json`/`matrix-go.json` preserve full frozen Go merge objects for
target identity/shared and subset facts/files/diagnostics. Source `matrix_real`
uses actual authenticated luac/LuaLS on two TOCs sharing one fixed Retail pin;
it does not represent multiple products. `prepare_matrix` is an explicit
test-only new-home source reader that freezes separate product observations;
its preparation is not run from production and does not perform game input.


`aggregates-cases.json`/`aggregates-go.json` preserve28 exact frozen-Go grouping,
HAVING, DISTINCT, empty inputs, wide sums and invalid aggregate cases. The test
compares exact decimal numeric values without narrowing to f64 or epsilon.
`aggregates-public.mjs` runs8 actual offline Map/ChrClasses local CASC cases,
retains full typed results/fixed source identities, and verifies successful CAPs.
A caller can freeze its executable with `LYCHEEDEV_RUST_BIN`; failures set a
nonzero process exit. This is selected aggregation parity, not full SQL/50%.

`matrix-public.mjs` exercises installed complete luac/LuaLS tools across four
fixed source products, preserving partial catalog coverage and verifying every
embedded capture. `broker-public.mjs` exercises the actual Retail opt-in broker
PID lifecycle, while `broker-complete-public.mjs` uses `prepare_broker`'s fresh
complete synthetic fixed catalog to check First/Second/Third cache semantics and
prune. Broker tests accept explicit binary/release/home/pin environment overrides.
Complete fixtures must be newly prepared because an existing authenticated cache
changes the intentionally cold first calls. `check_broker_lease` is a test-only
shared-core lease probe; it never replaces a query or calls Go in production.

`cte-cases.json`/`cte-go.json` cover14 frozen Go nonrecursive CTE scopes and errors;
`cte_parity` also checks shared budgets, borrowed physical rows, partial inputs
and exact lexical dependencies. `cte-public.mjs` exercises fixed local
Map/ChrClasses CTE providers, with additive verification claims checked separately.
`derived-cases.json`/`derived-go.json` retain16 frozen Go derived FROM/JOIN cases;
`derived-public.mjs` adds actual local providers and public error diagnostics.
`compound-cases.json`/`compound-go.json` retain16 frozen Go UNION ALL cases,
including first-branch names, full validation before outer LIMIT and lexical CTEs.
Their library tests keep partial coverage and shared budget checks distinct from
public CLI proof. Expression subqueries remain pending; recursive CTE evidence is recorded below.

`recursive-cases.json`/`recursive-go.json` preserve16 frozen-Go recursive
previous-delta UNION ALL, lexical scopes, wide integers, parameters and error
cases. `recursive_parity` also checks cycle work/memory admission, cancellation,
borrowed large unused cells, invalid unused values and partial completeness.
`recursive-public.mjs` is the sequential fixed Retail Map/ChrClasses CLI runner;
its generated report and artifact hashes, rather than fixture registration,
determine public parity. Expression subqueries and full SQL remain separate.
