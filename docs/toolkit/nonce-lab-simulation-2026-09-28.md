# Nonce Lab：协议、AVX2 与性能实验

2026-09-28。源代码与重跑方式见 [tests/nonce-lab](../../tests/nonce-lab/README.md)。生产桥未改动。新插件 `LycheeNonceLab` 已安装到 Retail；旧通信 Lab 的删除两次被自动审批以 `blocked by policy` 拒绝，因此旧目录仍保留，没有换工具绕过限制。

## 实现

- 固定 64 字节二进制头、16 字节 nonce、内联正文、24 字节尾部；先验证完整身份与小头，再访问大正文。
- AVX2 汇编同时过滤 32 个起点的首尾字节，完整候选交给精确比较；尾部与非 AVX2 CPU 回退标准库。
- 新协议取消独立 BODY 定位，但仍需要期望的 run/epoch/ticket。只有记录验证，不含挑战回执，不能证明 Lua 构造副本已提交。
- 模拟器动态分配 1 MiB 块，1/8 worker，无地址缓存；相邻块重叠、候选起点归属去重，覆盖字节不重复计算。

## 离线性能

同一个 256 MiB 驻留混合语料（随机/零/ASCII 页面），50 遍共 12.5 GiB 逻辑扫描量，三轮交错顺序，取中位数。每遍有 4094 条旧记录和一条新记录。通用 magic 对照也使用新记录布局，**不是旧真实客户端扫描器的原样重跑**。

| 搜索方式 | nonce A，1 worker | nonce A，8 worker | nonce B，1 worker | nonce B，8 worker |
|---|---:|---:|---:|---:|
| 通用 magic / Go 标准库 | 445.578 ms | 187.129 ms | 437.661 ms | 187.393 ms |
| 唯一 nonce / Go 标准库 | 418.179 ms | 180.120 ms | 426.792 ms | 184.120 ms |
| 唯一 nonce / 自写 AVX2 | 303.980 ms | 203.528 ms | 246.883 ms | 173.891 ms |

nonce A=`f7b2d83a6e19c45d90af317ce856a204`；B=`9c51a843dbe6720fb63d957ac218e04f`。AVX2 对标准库的单线程耗时降低 27.3% / 42.2%；8 worker 时分别慢 13.0% / 快 5.6%，不支持“一定更快”的结论。

加入每块复制到 worker 缓冲区后，nonce A 的结果：

| 搜索方式 | 1 worker | 8 worker |
|---|---:|---:|
| 通用 magic / 标准库 | 929.289 ms | 556.816 ms |
| nonce / 标准库 | 870.161 ms | 545.887 ms |
| nonce / AVX2 | 701.124 ms | 551.904 ms |

8 worker 下 SIMD 比 nonce 标准库慢约 1.1%，说明只优化匹配并没有稳定的整体收益。这里的复制仍是用户态内存复制，不包含 ReadProcessMemory、缺页、进程变化或真正独立的 13 GB 工作集，不能与旧真机 15.7 秒作直接倍数比较。

协议减少了候选：通用 magic 每遍 4095 个，唯一 nonce 每遍 2 个（头和尾各一份），最终均验证出 1 条记录。已知旧记录未被接受。候选降低约 2047 倍不等于总扫描速度提高同样倍数。

额外保留的 `00` 开头 nonce 压力组：标准库单线程 2809.203 ms，AVX2 257.005 ms。由于零页显著影响该前缀，这组用于说明数据依赖，不能作为一般提速宣传。

## 证据与测试

本机原始数据在 `.tmp/nonce-lab/benchmark*.json`，每次保留各 worker 的计划/实际字节和覆盖状态。三轮模拟每种方式均得到预期记录，覆盖完整。

Lua 5.1 与 Go 二进制编码一致；损坏、截断、旧 run/epoch/ticket、ACK 残留、无效地址候选、同内容不同 ticket、跨块边界、隔离缺口、覆盖去重测试通过。AVX2 与标准库进行了 28,672 组随机差分和密集锚点测试，并单独禁用 AVX2 验证回退。Go 标准库自身可能用汇编优化，因此这里并非“SIMD 对纯标量”。

以上仅为模拟结论，以下为独立真机结果。
