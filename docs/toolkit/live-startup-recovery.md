# 首次加载与连接恢复方案

日期：2026-09-24。范围：首次安装/升级后的接入、路径选择和 skill 编排。
这是当前问题的修复方案与验收清单，不代表首次加载真机测试已经通过。

## 已知问题与证据

本轮怀旧服尝试中，安装前插件为 absent，正式安装后为 managed；
身份识别返回 identity_unreadable、capture=frame、超时。随后使用正斜杠路径
连接，返回 candidate_missing 且候选为空。前者只证明未读到匹配身份回执，
不能证明插件未加载；后者在代码中存在明确原因：发现、选择、会话约束
直接比较路径字符串，正反斜杠及其他等价路径写法会被错误排除。

没有证据表明发生了线程或锁死锁。这里同时存在路径缺陷，以及首次加载
不能依赖一个尚未建立的插件会话的流程问题。

## 设计决策

保持现有原子命令，不增加一个包办安装、重启、登录、连接和运行探针的命令。
CLI 负责精确目标、协议、所有权和证据；skill 负责按观察结果组合动作。

1. **统一安装路径身份。** 发现筛选、候选选择、session 约束共用规范化比较：
   绝对路径、分隔符/点段清理、可解析的链接及短文件名、Windows 大小写。
   路径等价不合并窗口：同安装的不同 PID/HWND 仍是不同候选。
   每次输入前原有进程/窗口/角色核验仍成立。
2. **安装状态与运行状态分开解释。** managed 是磁盘文件匹配收据；身份回执
   才证明运行中的插件能响应。超时保留 unknown，不推断 absent、disabled 或
   reload_required。当前 candidate_missing 须结合 context.candidates 判断，
   空列表和包含 unreadable/busy 的列表不采取同一种恢复动作。
3. **先用已有上下文。** 有 operation 先恢复；有 session 先复用；有明确目标
   与 snapshot 直接 connect；只有目标未知才先 instances。用户限定 Classic
   时发现也限定 Classic，避免重复扫描及碰其他客户端。
4. **首次启用走独立的界面维护。** 插件不响应且无可用 session 时，先查看
   精确窗口的插件界面。已授权安装/游戏维护且支持桌面操作时，agent 根据
   实际界面完成启用或界面提供的重载，再用 CLI 建立连接。这一步不依赖
   addon bridge，也不把任意聊天文本加入 bootstrap 白名单。不宣称一次
   reload 一定能发现新插件；需要重登/重启时依据界面事实和已有授权处理。
5. **连接成功后回到原子流程。** reload 只重载；load/run/ack 分工不变。
   已授权任务需要重载时 agent 自动执行 live reload，不要求用户手输。
   连接不暗中重载，ACK 不清理重载。重载未决沿用 operation 恢复，不换请求
   键再次执行。首次启用后的成功标准仍是 fresh identity + ready，不是点击成功。

界面维护属于单独获授权的游戏操作，不是 CLI 后台输入能力。它必须遵守
目标窗口与所有权，不得抢占另一 agent 的未决任务。操作前检查目标的 busy
状态并协调该窗口的其他 live writer 暂停；无法确认时不发送界面输入。
现有 CLI 锁并不自动覆盖外部桌面工具，不能宣称两者已经具备跨进程原子互斥。
只读 source/data 工作无须暂停。桌面画面用于指导操作，游戏验收证据仍须 WGC。

## 实施与停止条件

- 本次代码修复：规范化发现/选择/session 三处路径约束及安装运行态索引；
  回归覆盖不同路径写法、首次连接、session 复用和排除其他安装。
- 本次 skill 修订：将上述失败分流放入按需加载的 live-startup 引用；
  live 调查与安装引用共同指向它，不重复协议实现、不虚构新命令。
- 原生桌面操作使用环境实际提供的工具及其初始化方式，不在 Go 或 skill
  中另造坐标脚本、键盘注入后门或常驻启动守护。
- 状态有实际变化后才重试一次连接；相同失败再次出现则结束该次输入尝试，
  保存诊断并继续定位。不循环 connect/reload，不让用户手输 `/dev connect`。
- 桌面工具不可用时明确报告缺少首次启用能力；不能通过放宽 session 要求、
  伪造 readiness 或无条件发送 `/reload` 来掩盖。

## 回归与交付标准

| 场景 | 验收结果 | 验证方式 |
| --- | --- | --- |
| 正反斜杠、尾分隔符、点段、相对路径、大小写 | 首次连接与 session 复用选中同一窗口，其他安装不接收输入 | Go 集成 fixture |
| 同安装多个窗口、另一安装在线 | 保留真实歧义，精确过滤无串输入 | 既有发现/连接测试及新增路径测试 |
| managed 但身份超时 | 不声称插件已加载或未加载；检查实际运行状态 | skill 场景评估 + 真机 |
| 游戏运行中首次安装、已安装但禁用、升级后仍运行旧版本 | 界面启用不依赖 session；后续 connect 有新身份和 ready 证据 | Classic/Retail/Titan 分别真机验收 |
| 黑屏、未登录、草稿/编辑焦点、战斗、忙碌窗口 | 按实际原因处理，不盲目 reload 或抢占 | 既有协议测试 + 真机 |
| 未决 reload/probe，另一个 agent 查数据 | 原 operation 恢复且不重放；数据工作独立 | Go 生命周期测试 + 真机 |
| 无桌面工具或不在维护授权内 | 明确能力/授权边界，不虚构新 CLI 能力 | skill 场景评估 |
