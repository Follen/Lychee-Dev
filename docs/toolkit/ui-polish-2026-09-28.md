WGC 原始图像 2560×1440。通过受管安装激活本轮 addon；没有覆盖复制游戏目录。
下面的 passed 仅限记录的场景，不等于整个客户端矩阵或发行验收通过。

## 本轮行为

- 连接接收期间：二维码右侧显示弹跳荔枝与“Agent 连接中”，透明输入层拦截
  游戏内鼠标、滚轮和键盘焦点。普通点击、焦点通知不取消事务；显式关闭、
  20 秒超时、战斗与离开世界释放输入。
- 执行前：输入层和焦点先释放；独立、可穿透的荔枝改为“探针运行中”。
  工作台输入与关闭不影响它；完整调查结束后荔枝、回执均消失。
- 事件、诊断、自动化统一工具栏、正文和页脚。事件无选择时省去空的选择区；
  自动化报告/详情互斥切换。执行器真实状态经可见页订阅刷新，运行中不再
  误报“已载入”，执行按钮禁用。
- 设置移除快捷键录制、保存和重置入口，仅展示有效按键帽。减少动效开关
  使用 Lychee 风格的圆角轨道与圆形滑块；减少动效保留静态活动标记。

## 恢复与离线回归

这轮实机发现并修复两个宿主恢复缺口：

- 持久化 reload 被物理按键占用挡在零消息投递时，可在原 OP 下重新核验并恢复；
  不能把零计数用于已经 staged、有 nonce、部分或未知投递的记录。
  `OP-8e52d3f08e6e392f0c4da3a5e2632a81` 原地恢复到报告核验及完整收尾，
  证据 `.tmp/ui-polish-visual-b-recover2.json`。
- bootstrap 在业务提交前中断，可以保持同一 BTP、意图和窗口 owner 重做握手，
  保留历史且总共最多三次。越过 commit fence 后不能重发。
  `BTP-0ae6f4abde7d1b3c90e8e4975d2d0895` 两次被已按下的物理键阻挡后，
  第三次 confirmed，证据 `.tmp/ui-polish-bootstrap-recover-c2.json`。
