# Asset investigation

Prefer a FileDataID from the relevant domain relationship. A community listfile
helps discover names; it is not an authenticated complete build inventory.
Search hits can have aliases or ambiguous variants, and a name miss proves no
file absence. Reuse the fixed Data pin and selected local/CDN source.

Discover inspect/export/demux inputs through CLI schema. Export already verifies
the requested file; an extra inspect is useful only for missing information.
Choose the requested encoding explicitly: a filename extension does not convert
bytes. Existing mip levels select pixels rather than resize them. Compare decoded
RGBA for lossless equivalence. A content variant selects actual Root flags;
locale alone cannot resolve it. AVI demux returns encoded frames/timing, not
images or a playable transcode. Preserve partial-output status.

Use an output location outside managed storage and replace existing files only
within scope. Retain source, file ID, encoding, byte count, hashes and captures.
Missing keys, integrity, ambiguity or size failures are not successful empty
exports. Offline misses remain missing prerequisites. Raw export requires the
complete verified file. After interruption inspect published files/manifests and
hashes before repeating: some files may already exist even without final stdout.
