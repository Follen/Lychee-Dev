# Installation tasks

Read `lycheedev schema update` for the installed CLI's update policy, supported
routes and effects. Keep a user-selected release and explicit targets. The CLI
owns version/channel selection; this Skill supplies neither. A plan describes
current targets without fetching a registry candidate. Deployment needed by an
authorized Live task does not itself authorize a global CLI update.

Use managed install/update/remove. Modified, unmanaged or conflicting targets
need diagnosis; never overlay-copy files, forge receipts or delete conflicts.
Keep the original transaction, release and targets after interruption. Read
component results and recovery state: executable replacement can finish before
payload synchronization. Preserve unrelated files and SavedVariables.

Filesystem completion does not activate a loaded addon or an existing Agent
context. Follow returned activation/recovery on each selected process within
scope. Finish compatible owned CON work before replacement; foreign or unresolved
ownership remains a blocker. Preserve older journals for matching-version
diagnosis rather than rewriting schemas, claims or reservations.
